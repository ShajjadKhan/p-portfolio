المنصة الرائدة

منصة "توريد فلو" (TawreedFlow)

نظام متكامل لأتمتة دورة مشتريات الفنادق والمجموعات الفندقية متعددة الفروع، صُمم خصيصاً للقضاء على هدر المراسلات غير المنظمة، وتطبيق المطابقة الثلاثية الذكية، والامتثال للفوترة الإلكترونية.

Multi-Tenant Architecture ZATCA Phase 2 E-Invoicing 3-Way Dock Reconciliation Saudi Cloud Native

أبرز الركائز الهندسية للمنصة:

  • القضاء على فوضى الواتساب: تحويل طلبات الشراء من محادثات مبعثرة إلى دورات اعتماد رقمية واضحة مرتبطة بميزانيات الأقسام.
  • مطابقة رصيف الاستلام الثلاثية (3-Way Match): مقارنة أمر الشراء (PO) وسند الاستلام الفعلي (GRN) وفاتورة المورد تلقائياً لمنع أي تلاعب أو فروقات أسعار.
  • الربط المشفر مع ZATCA: إنشاء وتشفير الفواتير الإلكترونية بصيغة XML UBL 2.1 مع رمز الاستجابة السريعة (QR) المطابق لمتطلبات المرحلة الثانية.
  • السيادة الكاملة للبيانات: استضافة سحابية مستقلة داخل المملكة متوافقة 100% مع متطلبات نظام حماية البيانات الشخصية.

الحوكمة والأمان

معايير الثقة والامتثال المؤسسي

بنية تحتية هندسية مصممة للشركات والمجموعات التي تتطلب أعلى درجات الموثوقية والسرية والالتزام بالتشريعات التنظيمية.

السيادة وتوطين البيانات (PDPL)

الالتزام التام بنظام حماية البيانات الشخصية الصادر عن (سدايا). يتم حفظ وتخزين ومعالجة قواعد البيانات بالكامل داخل مراكز بيانات معتمدة داخل أراضي المملكة.

الربط المعتمد مع زاتكا (ZATCA)

توليد الأختام الرقمية التشفيرية والتكامل السحابي المباشر مع منصة "فاتورة" (Fatoora) للمرحلة الثانية للفوترة الإلكترونية دون وسيط طرف ثالث.

سجلات تدقيق تشفيرية (Audit Trails)

تسجيل كل طلب شراء، اعتماد مالي، تعديل سعر، أو استلام بضاعة بسجلات مشفرة غير قابلة للتعديل أو الحذف، لحماية المؤسسة وضمان الشفافية المطلقة.

ملكية فكرية كاملة (100% IP)

تملك المؤسسة الكود المصدري وقواعد البيانات والبنية التحتية بنسبة 100% فور التسليم، دون أي قيود تقنية أو اشتراكات احتكارية متكررة.

أسلوب العمل

نماذج التعاقد والشراكة الهندسية

نماذج مرنة ومحددة النتائج تلائم احتياجات سلاسل الفنادق والشركات الناشئة والمؤسسات الكبرى.

الخيار الأكثر طلباً

بناء منصة متكاملة (Turnkey Platform)

تصميم وتطوير واختبار ونشر نظام سحابي متكامل من الصفر حتى مرحلة الإنتاج الفعلي، مع التدريب وتسليم الكود المصدري وضمان تشغيلي كامل لمدة 30 يوماً.

الأسئلة الشائعة

إجابات على استفسارات قيادات الأعمال

هل توقعون اتفاقية سرية وعدم إفصاح (NDA) قبل بدء المناقشات؟

نعم، بالتأكيد. نوقع اتفاقية ثنائية رسمية لحفظ السرية التامة قبل مراجعة أي تدفقات تشغيلية داخلية أو تفاصيل تسعير الموردين أو البنية التحتية الخاصة بمجموعتكم.

هل تستوفي المنصات المنفذة اشتراطات هيئة الزكاة والضريبة والجمارك (ZATCA)؟

نعم. يتم بناء محرك فوترة إلكترونية متوافق مع المرحلة الثانية يولد فواتير XML UBL 2.1 مشفرة بتوقيع رقمي ورقم UUID ورمز QR مطابق تماماً لاشتراطات الربط والتكامل المباشر.

من يمتلك الكود المصدري والبنية التحتية بعد الانتهاء؟

العميل يمتلك الكود المصدري وقواعد البيانات وحقوق الملكية الفكرية بنسبة 100%. لا توجد أي رسوم شهرية لاحقة مفروضة من طرفي، مع تسليم توثيق هندسي كامل.

أين يتم استضافة البيانات والخوادم؟

تُستضاف المنصات على خوادم سحابية محلية في الرياض أو جدة أو داخل بنية العميل الخاصة (On-premise)، بما يحقق الالتزام الصارم بنظام حماية البيانات الشخصية السعودي (PDPL).

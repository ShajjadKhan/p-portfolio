1. Executive Summary & Spatial Concept

Traditional digital newsletters and publication platforms restrict thought to linear, chronological feeds. BlockTree was architected as an infinite 2D spatial discourse hypergraph where editorial content branches dynamically across coordinates, allowing readers to explore complex topics non-linearly.

2. 2D Radial Collision Physics & Smooth Navigation

Displaying hundreds of interconnected editorial nodes on a single canvas requires robust physics simulation to prevent textual visual overlap:

  • Virtual Joystick Physics: Implemented 360° fluid canvas panning and pinch-to-zoom using responsive touch events, hardware-accelerated CSS transforms, and custom panzoom physics algorithms.
  • Radial Dynamic Collision Loop: Sibling nodes compute bounding radii in real-time. When a child branch expands, neighboring subtrees gently repel along angular vectors in under 15ms per frame.
  • Coordinate Anchoring: Node positions persist in SQLite using normalized spatial vectors, ensuring reproducible visual layout across client viewports of differing DPI.

3. Word-Grade Typography Studio

Authors write directly on the matrix using a custom browser typography engine:

  • Dual-Pane Synchronized Preview: Markdown editing pane with instant sub-pixel canvas rendering.
  • Structured Node Schema: Each publication block supports verified authorship cryptographic signatures, categorized tags, and parent-child branching links.
  • Content Moderation & 2FA: Multi-tier security featuring RFC 6238 TOTP two-factor authentication, PBKDF2 dummy hashing to prevent timing attacks, and pre-driver SQL injection sanitization.

4. Production Architecture

Powered by a lightweight Python/Flask backend and SQLite in WAL (Write-Ahead Logging) mode, BlockTree achieves microsecond read latencies without the operational overhead of heavy distributed graph databases.
